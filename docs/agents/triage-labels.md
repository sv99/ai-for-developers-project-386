# Метки триажа

Скиллы говорят в терминах пяти канонических ролей триажа. Этот файл отображает эти роли на фактические строки меток, используемые в issue-трекере этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                   |
| ------------------------- | --------------------- | ------------------------------------------ |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить этот issue       |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительную информацию   |
| `ready-for-agent`         | `ready-for-agent`     | Полностью специфицирован, готов для AFK-агента |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком               |
| `wontfix`                 | `wontfix`             | Не будет выполнен                          |

Когда скилл упоминает роль (например, «примени метку готовности к AFK»), используйте соответствующую строку метки из этой таблицы.

Отредактируйте правую колонку под ту терминологию, которой вы реально пользуетесь.
