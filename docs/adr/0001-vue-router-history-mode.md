# SPA-маршрутизация: vue-router в history-режиме

Приложение из одного экрана-лендинга превращается в многостраничный сервис (главная, страница записи, предстоящие события): URL нужны для ссылок и кнопки «назад» браузера. Решено: `vue-router` с `createWebHistory` — чистые адреса вида `/booking`, dev/preview Vite отдают SPA-fallback.

## Considered Options

- Ручной переключатель (флаг текущей страницы) — отклонён: нет URL и истории браузера, а ссылка на страницу записи — ключевая функция сервиса бронирования.
- `createWebHashHistory` (`/#/booking`) — отклонён: грязные адреса; был бы оправдан только на статическом хостинге без fallback.

## Consequences

- Появление статического хостинга без SPA-fallback (например, GitHub Pages) потребует пересмотра режима.
