# Настройки владельца на `/admin`: имя календаря и Типы событий

Владельцу нужна отдельная страница настроек: на ней он задаёт имя календаря и добавляет Типы событий. Держать управление типами на странице Предстоящих событий (`/upcoming`) неудобно: та страница — про Записи, а не про настройку.

Решено:

- `/admin` — настройки владельца: имя календаря и Типы событий (список + добавление);
- `/upcoming` — Предстоящие события: журнал будущих Записей (тикет #20), без управления типами;
- имя календаря по умолчанию — «Владелец»; показывается посетителю в блоке владельца на экране выбора (`/events`);
- навигация в шапке: «Записаться» → `/events`, «Предстоящие события» → `/upcoming`, «Настройки» → `/admin`.

## Considered Options

- Оставить управление типами на `/upcoming` — отклонено: смешивает настройку и журнал Записей.
- Сделать `/admin` полной заменой `/upcoming` — отклонено: журнал Записей остаётся отдельным взглядом владельца.

## Consequences

- Дополняет карту экранов ADR-0002: управление типами переезжает с `/upcoming` на `/admin`.
- Термин «владелец календаря» сохраняется (GLOSSARY.md); в интерфейсе используется пункт «Настройки», а не «админка».
- Редактирование и удаление Типов событий по-прежнему вне v1.
